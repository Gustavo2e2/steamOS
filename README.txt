PLAYDECK — biblioteca pessoal de jogos

COMO ABRIR
1. Extraia a pasta PLAYDECK do arquivo ZIP.
2. Abra o arquivo index.html com dois cliques.
3. O site funciona diretamente no navegador, sem instalar programas e sem servidor.

COMO ADICIONAR JOGOS
1. Clique em “Adicionar jogo”.
2. Informe nome, gênero, plataforma e status.
3. Para a capa, cole uma URL de imagem ou escolha um arquivo do computador.
4. Clique em “Salvar jogo”.

RECURSOS
- Pesquisa por nome, gênero e plataforma.
- Filtros: todos, instalados e quero jogar.
- Navegação por gênero, biblioteca e favoritos.
- Cadastro, edição e exclusão de jogos.
- Capa por URL ou imagem local.
- Link externo para página do jogo.
- Backup e restauração da biblioteca em JSON.
- Layout adaptável para computador e celular.

ONDE OS DADOS FICAM
Os jogos ficam salvos no armazenamento local (localStorage) do navegador e neste computador/perfil de navegador. Não existe conta, servidor ou sincronização automática. Use os botões de exportar/importar para criar e restaurar backups.

OBSERVAÇÕES
- As imagens iniciais são carregadas da CDN pública de imagens da Steam; para exibi-las é necessária conexão com a internet.
- Você pode substituir as capas por imagens locais.
- O botão “Abrir página” usa o link externo informado. Um site aberto em um navegador comum não pode executar diretamente jogos .exe instalados no computador por razões de segurança.
- Este projeto é uma biblioteca pessoal, não uma loja com pagamentos ou downloads hospedados.
